# Email / Klaviyo MCP Integration

## Setup

1. Скопируй `.env.example` в `.env` и вставь API ключ:
   ```
   cp .env.example .env
   ```
2. Получить API ключ: https://www.klaviyo.com/account#api-keys-tab

## MCP Server

Проект использует официальный Klaviyo MCP сервер (`@klaviyo/klaviyo-mcp`), который запускается автоматически через `.mcp.json`.

### Доступные возможности

| Категория | Действия |
|---|---|
| Email кампании | Создание, отправка, управление черновиками |
| Профили | Создание, обновление, поиск, получение по ID |
| Сегменты | Создание, управление, получение членов |
| Аналитика | Метрики кампаний, события, статистика |

## Переменные окружения

| Переменная | Описание |
|---|---|
| `KLAVIYO_API_KEY` | Приватный API ключ Klaviyo (начинается с `pk_`) |
